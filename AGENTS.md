# AGENTS.md — kaggle-qwen-bridge

Публічний репозиторій: Qwen3-Coder-30B на Kaggle + найпростіший MCP-міст для Claude.

## Правила
- Лише стандартна бібліотека Python.
- Репозиторій публічний: жодних секретів. Токени Kaggle, рядок `BRIDGE_ENDPOINT` із реальним токеном,
  `endpoint.json`, адреси приватних серверів не комітити; у прикладах лише плейсхолдери.
- Тут описано тільки Kaggle, модель і міст. Клієнтські оболонки й інтерфейси — поза цим репозиторієм.
- Твердження в README/docs мають статус «перевірено» або «не перевірено», як зараз.
- Серверну логіку (`kernel/serve.py`) змінювати лише разом із тестом у `tests/`.
- Самотест ядра витрачає квоту GPU (≈ 6 хв): не гонити без потреби.

## Перевірка
`python -m unittest discover -s tests -v` (14 тестів, без Kaggle).
